## 2. Задание

Вариант 10: найти строку в массиве с максимальной суммой элементов. Размер массива: N = 6, M = 6.

Требуется:

1. Разработать алгоритм решения.
2. Реализовать алгоритм на языке ассемблера RISC-V.
3. Реализовать алгоритм на языке Си.
4. Скомпилировать Си-код компилятором для RISC-V и получить дамп-файл.
5. Продемонстрировать работу программы в симуляторе Venus.

Обработка массива выполнена в виде отдельной функции с аргументами, передаваемыми согласно соглашению о вызовах (ABI) RISC-V.

## 3. Алгоритм

Двумерный массив хранится в памяти построчно (row-major), поэтому элемент `(i, j)` находится по смещению `i * M + j` (в словах).

1. Установить `best_sum = INT_MIN`, `best_idx = 0`.
2. Для каждой строки `i` от 0 до N − 1:
   1. вычислить сумму `sum` всех M элементов строки;
   2. если `sum > best_sum`, то `best_sum = sum`, `best_idx = i`.
3. Вернуть `best_idx` и `best_sum`.

Если несколько строк имеют одинаковую максимальную сумму, возвращается первая из них (используется строгое сравнение).

Сложность: O(N · M) по времени, O(1) по дополнительной памяти.

## 4. Интерфейс функции (ABI)

Функция `find_max_row` в ассемблерной версии:

| Регистр | Назначение |
|---------|------------|
| `a0` (вход)  | адрес начала массива |
| `a1` (вход)  | N — число строк |
| `a2` (вход)  | M — число столбцов |
| `a0` (выход) | номер строки с максимальной суммой |
| `a1` (выход) | значение максимальной суммы |
| `ra`         | адрес возврата (`jal` / `ret`) |
| `t0`–`t5`    | временные регистры (caller-saved) |

Функция является листовой (не вызывает других функций) и использует только временные регистры `t0`–`t5`, поэтому ей не нужен стековый кадр. Вызывающая функция `main` сохраняет результат в регистрах `s0` и `s1`, так как вызовы `ecall` могут изменять `a0` и `a1`.

В версии на Си сумма возвращается через указатель (четвёртый аргумент), а номер строки — как значение функции.

## 7. Сборка и получение дампа

Компиляция Си-программы с флагами `-march=rv32i -mabi=ilp32`:

```
riscv-none-elf-gcc -march=rv32i -mabi=ilp32 main.c -o main.elf
riscv-none-elf-objdump -D main.elf > main.dump
```

(для набора инструментов `riscv64-unknown-elf-` команды аналогичны, меняется только префикс).

В дампе функция `find_max_row` находится по адресу `0x101c0`. Поскольку набор команд `rv32i` не содержит расширения M (умножение), выражение `i * cols` в Си-версии компилятор заменяет вызовом библиотечной функции `__mulsi3`. В ассемблерной версии умножение не требуется: указатель на элемент просто увеличивается на 4 байта.
